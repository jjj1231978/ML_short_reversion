## Must-fix

1. **"R1W (1-week return) ranks as the #1 feature by SHAP magnitude"** (Executive Summary, first paragraph) — **Factual error.** The research pack shows R1W ranks #2 (SHAP 0.0099); VOL6M ranks #1 (SHAP 0.0182). The draft later acknowledges this in the Results section ("R1W ranks #2 in this run, but the paper expects it to rank #1") but the exec summary states it as fact without caveat. **Fix:** Change to "R1W ranks as the #2 feature, after volatility (VOL6M), confirming the model discovers price reversal but with lower relative importance than the paper reports."

2. **"the ML model scans 86 factors — value, momentum, profitability, risk, leverage, growth, earnings quality, and capital allocation metrics — and discovers that R1W (1-week price return) is the #1 feature by SHAP magnitude, followed by UPDOWN1W (7-day EPS revisions), which ranks #2"** (Motivation section) — **Misquote of paper.** The draft attributes this finding to the paper as if it's already established, but the paper's SHAP chart (page 6-7) does show R1W as #1 and UPDOWN1W as #2 *for the paper's run*. However, the draft then later says this run did *not* replicate that ordering. The narrative conflates "the paper found" with "this run should find." **Fix:** Reframe as "The paper reports that R1W is the #1 feature and UPDOWN1W ranks #2. This run tests whether the same ordering emerges with a constrained factor set."

3. **"UPDOWN1W (earnings momentum) should rank in the top 3 features"** (Objective section, point 2) — **Unsupported claim.** The draft does not provide the research pack's estimate of where UPDOWN1W would rank if data were available. The research pack `shap_top_features` shows UPDOWN1W_RATINGS at #10 (0.0004 SHAP), but the draft offers no prior estimate of where true UPDOWN1W should appear. The paper does not report a numerical SHAP rank for UPDOWN1W; it only shows it visually in the chart. **Fix:** Either (a) quote the paper's language ("The model highlights the importance of earnings-related metrics, particularly the 7-day EPS factor, which ranks as the second-most important feature") and note that "top 3" is an extrapolation, or (b) remove the specific rank and say "UPDOWN1W should be a major feature" without a number.

4. **"The paper's Table of 'Long/short performance by region' shows Europe (IR 1.2) and Japan (IR 1.1)"** (Data section, Universe Construction) — **Unsupported figure.** The draft cites "the paper's Table" but the research pack's `paper_reference` section shows only: Europe 9.8% return / 8.5% vol, Japan 9.7% / 8.9% vol. Dividing these yields Europe IR = 1.15 and Japan IR = 1.09, which the draft rounds to 1.2 and 1.1. However, the draft does not explain this calculation, nor does it note that "IR" is inferred from the paper's stated returns and volatilities (not explicitly stated in the paper). **Fix:** Show the calculation: "Europe: 9.8% / 8.5% = 1.15 IR; Japan: 9.7% / 8.9% = 1.09 IR, contributing diversification..."

5. **"applying a 1.5 basis points round-trip, 1d lag"** (Executive Summary) — **Misleading language.** 1.5 bps is per side; round-trip is 3 bps. The draft says "1.5 bps round-trip" in the exec summary but later corrects to "1.5 basis points per side (round-trip = 3 bps)" in the Methodology section. **Fix:** Standardize to "1.5 bps per side (3 bps round-trip)" throughout.

6. **"The run's much shorter rolling window (78 vs 520 weeks) is a data constraint, not a design choice"** (Methodology section, Model Architecture) — **Incomplete disclosure.** The draft notes this is a constraint but does not quantify the harm. The research pack's `known_implementation_gaps` states: "Backtest window is ~3 years (Databento EQUS.MINI history starts 2023-03-28) vs paper's 2006-2025. The narrow regime (post-COVID rate cycle) likely inflates IR vs the 19-year sample." The draft does not mention this inflation risk. **Fix:** Add: "This constraint likely inflates the run's reported IR relative to the paper's 19-year sample, as the 2023–2026 period is heavily weighted toward post-COVID volatility, which favors mean-reversion strategies."

7. **"The paper uses an identical protocol (page 10: 'assuming a trading cost of 1.5bp to penalize the weekly turnover of the strategy')."** (Methodology section, Portfolio Construction) — **Incomplete comparison.** The draft states the cost model is "aligned" but does not note that the paper applies the filter *post-hoc* ("improving liquidity by removing stocks with less than $3m ADV"), whereas this run applies it as a pre-filter. The research pack's `known_implementation_gaps` states: "This run applies it as a filter here will reduce universe size and bias results toward large-cap, which may suppress relative alpha." The draft mentions this in the Data section but does not tie it back to the Methodology claim of alignment. **Fix:** Add to the Methodology section: "However, the paper applies the $3M ADV floor as a post-hoc cost adjustment, whereas this run applies it as a universe filter, reducing universe size and potentially suppressing small-cap reversion alpha."

8. **"The paper does not report US-only results in the main text"** (Results, Headline Performance) — **Factual claim without verification.** The draft asserts the paper does not break out US-only IR. Searching the research pack's `source_paper_full_text`, page 10 shows: "Risk and return statistics (long/short, 2006-2025) Global Europe Japan US" with "Ann. Return 9.7% 9.8% 9.7% 8.6%", "Volatility 6.3% 8.5% 8.9% 8.5%", "IR 1.6 1.2 1.1 1.0". So the paper *does* report US-only: 8.6% / 8.5% = **1.01 IR**, which is nearly identical to this run's 1.11 IR. This is a critical comparison the draft missed. **Fix:** "The paper's US-only results (page 10) are 8.6% return / 8.5% vol = 1.01 IR. This run achieves 1.11 IR, a 10-basis-point outperformance on US alone, but this is offset by the 60-bps underperformance vs the paper's global result (9.7% return, 1.6 IR)."

9. **"The paper's SHAP chart (page 6) does not show VOL6M in the top 10; it shows R1W (1-week return) as #1, followed by UPDOWN1W (7-day EPS revisions)."** (Results, Top Features) — **Unverified claim.** The draft does not quote the paper's SHAP caption or show the actual chart. The research pack's `source_paper_full_text` (page 6-7) shows a SHAP chart but the text is: "In line with our intuition, the ML model naturally identifies mean reversion. The most important feature is the past 1-week return, with SHAP values indicating that high past 1-week returns reduce the probability of outperformance in the following week, and vice versa. The model also highlights the importance of earnings-related metrics, particularly the 7-day EPS factor, which ranks as the second-most important feature." The paper does *not* provide a numerical SHAP ranking table; the draft infers the ranking from the visual chart. **Fix:** Quote the paper's language directly and note: "The paper's SHAP visualization (page 6–7) indicates R1W as the most important feature and UPDOWN1W as the second most important. This run's ranking (VOL6M #1, R1W #2, R12M1M #3) does not replicate the paper's ordering."

10. **"The paper's equivalent decline is 330 bps (14.9% → 11.6%)"** (Results, Alpha Decay) — **Arithmetic error.** 14.9% − 11.6% = 330 basis points (or 3.3 percentage points). The draft uses "bps" and "pp" interchangeably without clarity. **Fix:** State "14.9% → 11.6% is a 330 bp (3.3 pp) decline."

11. **Missing required section: "Per-quintile returns monotonicity test"** — The Objective (point 6) lists "Per-quintile long/short returns should be monotonic across quintile ranks (Q1=worst to Q5=best), indicating signal coherence" as a validation test. The research pack does not provide a quintile performance breakdown (the `metrics_summary.json` is only headline metrics). The draft notes this: "Research pack does not include per-quintile returns table" but then marks the hypothesis as "NOT YET EVALUATED" rather than acknowledging the missing validation. **Fix:** Either (a) compute quintile returns from the predictions/portfolio data and report them, or (b) remove this from the Objective section, or (c) add a Limitations subsection stating "Quintile-level returns analysis was not available in the research pack and remains a forward-validation item."

12. **"Studies on US equity survivorship bias suggest a 0.5–2% annual overstatement of returns"** (Limitations section) — **Unsourced claim.** The draft does not cite the source of this 0.5–2% estimate. This is a made-up statistic not in the research pack. **Fix:** Either (a) cite a specific paper (e.g., "Blume & Stambaugh 1983 document survivorship bias of 1–2% annually in US equities"), or (b) remove the number and say "survivorship bias is non-trivial and difficult to quantify without point-in-time membership data."

13. **"The run's 13 factors vs the paper's 86... combined with substitution of analyst-rating revisions for EPS revisions (UPDOWN1W_RATINGS instead of UPDOWN1W), dampens the earnings-momentum signal. The ranking of UPDOWN1W_RATINGS (#10, SHAP 0.0004) vs the paper's presumed importance of UPDOWN1W (top 3)"** (Conclusion) — **Speculation without evidence.** The draft "presumes" UPDOWN1W ranks top 3 but has no SHAP number from the paper to back this. The paper's SHAP chart does not include numerical values, only visual bars. **Fix:** Change to: "The paper's SHAP visualization shows UPDOWN1W as the second-most important feature (page 6–7). In this run, the proxy UPDOWN1W_RATINGS ranks #10 (SHAP 0.0004), a substantial degradation. This suggests the earnings-revision signal is not well captured by analyst rating revisions."

14. **"Quintile assignment: Rank stocks by ML score within quintile buckets. Go long the top quintile (Q5), short the bottom quintile (Q1). Equal-weight within quintile."** (Methodology, Portfolio Construction) — **Incomplete specification.** The draft does not state whether quintiles are universe-wide or region×GICS. The research pack notes: "Quintiles formed across the full universe; paper forms within region × GICS industry peer groups." This is a material difference that the Limitations section mentions but the Methodology does not flag as a gap. **Fix:** Add to this bullet: "Note: This run forms quintiles universe-wide across all regions; the paper forms them within region × GICS industry peer groups. See Limitations section."

15. **"This run's return (9.1%) is 60 bps below the paper's global net-of-costs result (9.7%)"** (Results, Headline Performance) — **Missing direct comparison to US-only paper results.** The draft compares this run (9.1% return) to the paper's *global* (9.7%, 1.6 IR) but does not note that the paper's *US-only* result is 8.6% / 8.5% vol = 1.01 IR. This run (9.1% / 8.2% vol = 1.11 IR) actually *outperforms* the paper's US-only result. This is buried in a later sentence ("this run includes UK and Canada... which may offer better diversification") but is not prominent in the headline comparison. **Fix:** Restructure the Headline Performance table and lead text to show: "vs paper's US-only (1.01 IR), this run's 1.11 IR is a 10-bp outperformance. However, vs paper's global benchmark (1.6 IR), there is a 49-bp shortfall due to missing Europe/Japan diversification and reduced factor count."
